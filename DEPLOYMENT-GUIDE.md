# How to Deploy Your Devotional App as a Live Website

## Option 1: GitHub Pages (Recommended - FREE)

### Steps:
1. Create a GitHub account at https://github.com (if you don't have one)

2. Create a new repository:
   - Click "New repository"
   - Name it: `devotional-app` (or any name you like)
   - Make it Public
   - Click "Create repository"

3. Upload your HTML file:
   - Click "uploading an existing file"
   - Rename your HTML file to `index.html`
   - Drag and drop the file
   - Click "Commit changes"

4. Enable GitHub Pages:
   - Go to Settings → Pages
   - Under "Source", select "main" branch
   - Click Save
   - Your site will be live at: `https://yourusername.github.io/devotional-app/`

**Time: 5 minutes**
**Cost: FREE**

---

## Option 2: Netlify (Super Easy - FREE)

### Steps:
1. Go to https://www.netlify.com/
2. Sign up (free)
3. Drag and drop your HTML file (rename to `index.html`)
4. Done! You get a live URL instantly

**Time: 2 minutes**
**Cost: FREE**

---

## Option 3: Vercel (FREE)

### Steps:
1. Go to https://vercel.com/
2. Sign up with GitHub
3. Import your repository or drag & drop files
4. Deploy

**Time: 3 minutes**
**Cost: FREE**

---

## Option 4: Render (FREE)

### Steps:
1. Go to https://render.com/
2. Sign up
3. Create a new Static Site
4. Connect your GitHub repo or upload files
5. Deploy

**Time: 5 minutes**
**Cost: FREE**

---

## My Recommendation:

**Use Netlify** - It's the easiest:
1. Just drag your HTML file
2. Get instant live URL
3. Can add custom domain later

**Or use GitHub Pages** if you want to learn Git (good for future projects)
